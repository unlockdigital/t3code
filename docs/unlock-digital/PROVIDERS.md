# Provider connections and usage

Use **Settings → Providers** to add connections with clear labels such as `Work · Subscription` or `Research · API`. Separate connection homes preserve multiple accounts for the same provider. Subscription access and API credits can have separate entitlements, limits, and bills.

Follow the provider's supported login flow or enter an API key through its designated credential control. Keep keys out of chat messages and source files. A successful sign-in establishes identity; model availability and remaining quota depend on the provider.

The usage view displays provider-reported evidence with its account and update time. Codex five-hour and weekly windows, Claude spending budgets, and shared provider pools describe different limits. Missing evidence remains unknown. API balances and subscription allowances have separate billing pages.

Account routing is a recommendation preview. Automatic dispatch stays disabled. Select an account and model explicitly for a task, and review provider terms for sensitive work.
