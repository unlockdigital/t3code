# Preview qualification and roadmap

This release targets Apple-silicon macOS plus source. The release validation record identifies completed checks and remaining destination-side acceptance.

Try a disposable project with a newly configured provider. Check account/model selection, browser permission, usage evidence, handoff export with an attachment, Home/unread navigation, and a scoped delegated task. Quit and reopen to confirm persistence.

Future work can qualify additional installer platforms, signing/notarization, an authenticated fork update feed, and multi-computer use. Experimental helper dispatch and delegated approval require their own security and usability qualification before inclusion.
