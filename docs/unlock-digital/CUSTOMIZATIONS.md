# Included fork improvements

This preview integrates official T3 Code v0.1.6 with:

- Home activity and unread navigation, with background chats continuing as you navigate.
- Multi-account labels distinguishing subscription connections and API credentials, clearer usage windows, and account routing previews.
- Conversation links, Markdown export, and environment-scoped agent handoffs with local attachment references and snapshots.
- A dedicated Upstream Updates settings panel for release/advisory evidence and isolated update preparation.
- Project browser capability resolution and fail-closed private-route handling.
- Project briefs, workflow review history, and structured skill metadata.
- Wider model selection with readable model/account names and reasoning controls.
- A compatibility bridge for older fork databases and an intrinsically isolated Mac preview identity.

Normal scoped delegation remains available. Experimental private-helper dispatch, delegated approval tools, and the Teddy/N2ition integration are deferred from this distribution. Historical metadata is retained for compatibility and grants no excluded runtime capability.

Auto is the default access mode. Each provider translates permissions through its own adapter; review permission prompts and project settings before granting broader access.
