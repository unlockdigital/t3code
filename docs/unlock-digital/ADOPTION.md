# Evaluating this fork

Unlock Digital maintains this fork of [T3 Code](https://github.com/pingdotgg/t3code). This preview integrates official v0.1.6 and selected fork improvements. Read the release's source revision, checksums, validation record, and signing status before installation.

Provider sign-ins and API billing remain subject to each provider's terms and entitlements. Agents can read files, invoke tools, and run commands within the permissions you grant. Start with a disposable project and Auto permissions. Configure project browser access deliberately.

The preview has a separate desktop identity and default application profile. Explicit environment overrides can select other profiles. Preserve a compatible application and data backup together before moving existing data between versions. See [installation](PORTABLE_TRIAL.md) and [maintenance](UPSTREAM_SYNC.md).
